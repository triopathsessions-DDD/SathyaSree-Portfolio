# Sathyasree Portfolio

A responsive personal portfolio website built to showcase Sathyasree's skills, education, experience, projects, and contact information.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* HTML5
* CSS3
* JavaScript

## Features

* Responsive design for desktop, tablet, and mobile
* Home, About, Education, Experience, Skills, Projects, and Contact pages
* Interactive navigation
* Dark and light theme support
* Smooth page transitions
* Click sparkle interaction
* Scroll-to-top functionality
* Responsive project cards
* Profile image lightbox
* Mobile-friendly layout
* Clean and modern UI

## Installation

Clone the repository:

```bash
git clone https://github.com/triopathsessions-DDD/SathyaSree-Portfolio.git
```

Go to the project folder:

```bash
cd SathyaSree-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will be available at:

```text
http://localhost:5173/
```

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
